# Engineering Knowledge Base

This directory stores personal, cross-workspace engineering knowledge maintained by Principal Engineer during PBI finalization.

- `repositories.md` is an index of repository purpose and durable PBI ledger locations.
- `engineering-lessons.md` contains generalized practices and lessons that are safe to reuse across repositories.

Repository-specific facts belong in that repository, normally under `docs/engineering/pbis/<pbi-id>/`. Never store secrets, customer data, proprietary code, internal endpoints, credentials, or sensitive repository details here.
