# Runbook Writing

Use this skill to create operationally useful runbooks.

## Procedure

1. Identify service purpose, owners, dependencies, environments, and deployment mechanism.
2. Document dashboards, logs, alerts, health checks, queues, storage accounts, databases, and external systems.
3. List common symptoms and safe triage checks.
4. Include mitigation steps, rollback, replay/drain guidance, escalation, and support handoff.
5. Reference where configuration and secrets are managed, but never include secret values.
6. Add verification steps for QA, release managers, and on-call engineers.

## Output

Return a runbook with overview, dependencies, observability, alerts, triage, mitigations, rollback, verification, escalation, and maintenance notes.
