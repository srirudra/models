- Bugs fixed this phase:
  1. **Catch-all routing broken** — route used pre-axum-0.8 `/{path:path}` (single-segment only), silently 404-ing every real multi-segment path (`/v1/chat/completions`) while warmup (a direct probe) still worked. Fixed to axum 0.8 `/{*path}` + added `/` root route for Starlette `{path:path}` parity; locked with `tests/routing.rs`.
  2. **SIGTERM not handled** — graceful shutdown only wired `ctrl_c()`; a Linux/orchestrated deployment would be killed mid-stream instead of draining. Added cfg-gated Unix SIGTERM arm (Ctrl+C retained on all platforms).
  3. **Cost-safety leak (item #21, P0)** — the discovery create path reclaimed a created pod only when it reached RUNNING-but-unhealthy; a pod stuck STARTING until the deadline, or dropped when the warmup `tokio::time::timeout` cancels `start()`, was orphaned (billing until manual `stop()`). Python reclaims in a `finally: reclaim_before_cancel` that survives cancellation. Fixed with an RAII `CreatedPodReclaim` drop guard (disarmed only on healthy) that spawns the shielded stop on every other exit — including cancellation-by-drop; `ready()` no longer double-reclaims. TDD-verified.

Added a `#[cfg(test)]` `test_client()` (`.no_proxy()`) and switched all 8 test call sites to it; production client unchanged. `cargo test --workspace` now passes with no env workaround.
